gotchas:
  - title: "Enter sends, so a pasted prompt gets cut at the first blank line"
    body: "Paste a multi-paragraph prompt and only the opening sentence is submitted. You get a scope with no task and Copilot asks what you actually want. Happened live. Every prompt here copies as one unbroken block. Use Shift+Enter if you need a line break yourself, and check the sent bubble contains your last sentence before you talk over it."
  - title: "Auto is the model picker, not the mode"
    body: "The pane shows an Auto dropdown that chooses the model. The mode control is the separate pencil icon beside it. Confirm which one you are on before you claim a mode on stage."
  - title: "A new skill takes about fifteen minutes to appear"
    body: "Measured 16 Sep 2026. Uploaded, pressed Refresh repeatedly, nothing for ten minutes, then it appeared on its own. The file was correct the whole time. Do not start deleting and re-uploading while you wait — you will convince yourself something is broken when it is not."
  - title: "Copilot silently skips a folder whose name does not match SKILL.md"
    body: "No error, no warning. Microsoft documents this as the supported way to hide a skill without deleting it, which is exactly why it fails invisibly. If a skill will not load, check the folder name first, then check the file is SKILL.md and not SKILL.md.txt."
  - title: "Uploaded skills arrive enabled"
    body: "You do not need to switch them on. And the toggle only controls automatic selection — an explicit @mention still runs a disabled skill, so it is not a security control. Say that plainly if asked."
  - title: "Do not use =COPILOT()"
    body: "Microsoft retired the preview worksheet function on 14 September 2026. Use the pane."

          # Format a finance sheet for the board

          Method version: 1.0.

          1. Work only on the worksheet and table I name. Never change a value, a formula or the row order. Ask if the target table is unclear.
          2. Do not assume the table starts at row 1. Find the actual header row first.
